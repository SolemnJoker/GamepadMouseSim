# Delta Spec: live-help-screen

## Purpose

让操作帮助提示始终与运行时实际生效的映射一致:帮助屏改为按当前配置实时渲染,配置修改后立即反映,替代构建时生成的静态帮助图。

## ADDED Requirements

### Requirement: 帮助内容与生效映射一致

帮助屏展示的按键说明 SHALL 按当前生效映射(配置 + 共享默认表的合并视图)实时生成:展示内容与运行时行为、设置界面显示同源一致。构建期预生成的静态帮助图 SHALL 不再作为帮助屏内容来源。

#### Scenario: 默认内容一致

- **WHEN** 用户以默认配置呼出帮助屏
- **THEN** 展示的按键-动作对应关系与代码默认表一致(不再出现"帮助写 View=退出、实际 View=Tab"类的漂移)

#### Scenario: 自定义映射反映

- **WHEN** 用户把某按钮映射改为其他动作后呼出帮助屏
- **THEN** 该按钮的说明展示为新动作

### Requirement: 配置热加载后即时反映

配置经热加载变更(含 profile 切换)后,下一次呼出帮助屏 SHALL 展示最新生效映射;帮助屏已打开期间配置发生变更的,展示内容 SHALL 在配置变更后更新或于下次呼出时生效(实现取其一并保持一致)。

#### Scenario: 改配置后呼出

- **WHEN** 用户修改映射配置,等待热加载生效后呼出帮助屏
- **THEN** 帮助屏展示的是修改后的映射

#### Scenario: profile 切换后呼出

- **WHEN** 用户切换 profile 后呼出帮助屏
- **THEN** 帮助屏展示新 profile 的映射

### Requirement: 帮助屏展示质量与可用性

帮助屏 SHALL 保持现有展示形态(全屏 85% 区域、中文、分区布局),在常见分辨率(1080p)下文字清晰不重叠;呼出与关闭行为(自动消失、再次呼出)与现状一致。帮助内容的构建 SHALL 有自动化测试覆盖(内容数据层),视觉呈现允许 manual smoke。

#### Scenario: 1080p 显示

- **WHEN** 1080p 显示器上呼出帮助屏
- **THEN** 各分区文字清晰、无重叠、布局完整
